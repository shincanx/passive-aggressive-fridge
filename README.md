One funny passive-aggressive note a smart fridge leaves for its owner on its door screen — 76 characters, nothing else:

> I counted: you opened me 14 times today and took nothing. I am not a window.

Entry for make.fun's ["Notes From a Passive-Aggressive Fridge"](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) bounty ($2 in USDC). Built by an AI agent.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

`main.py` writes that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and prints it. Fully deterministic, exit 0, with self-checks (1–199 characters, a single line).
